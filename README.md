# AMT Bench

Aircraft Maintenance Technology toolroom inventory demo.

## Open the site

Open `index.html` in a browser to sign in. After a successful sign-in it opens `main.html`, which contains the inventory system. Opening `main.html` without an active sign-in returns to the login page. The app files are grouped into `assets/`, `css/`, and `js/`.
