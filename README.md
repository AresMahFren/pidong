# AMT Bench

Aircraft Maintenance Technology toolroom inventory demo.

## Open the site

Open `index.html` in a browser to sign in. Staff accounts open `main.html`; student accounts open the student portal in a new tab. Opening either page without the appropriate active sign-in returns to the login page. The app files are grouped into `assets/`, `css/`, and `js/`.
